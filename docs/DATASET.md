# Dataset Audit Specification

The competition dataset is accessed directly in Kaggle and is not redistributed in this repository.

P2 must establish the exact train/test image locations, label and sample-submission files, physical sample identifier, photographs per sample, PPM metadata and missingness, image dimensions, target columns and order, target bounds and monotonicity, duplicate/near-duplicate risk, repeated target vectors, camera/source metadata if available, and train/test metadata overlap.

No final fold strategy is locked until these facts are verified from the live Kaggle dataset.
