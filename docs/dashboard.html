Tujuan

Mengestimasi persentase massa lolos saringan dari 2–5 foto satu tanah. Membantu skrining awal dan riset photogranulometry.

Kurva valid 100%, lebih baik dari baseline pada grouped CV, serta inferensi ulang identik dari checkpoint tersimpan.

01 / Data journey

Satu tanah, banyak foto, satu kurva.

Pilih tahap untuk melihat masukan, keluaran, dan alasan transformasinya. Foto satu sampel selalu berada dalam kelompok yang sama.

Diagram dari implementasi

Dua jalur prediksi

A-track: granulometry, Fourier, gradien, LBP dan warna → CLR → ridge / PLS / kNN.

C-track: tile → GrainEncoder → pooling → head terkendala → CDF. Baseline dan jaringan saling dibandingkan sebelum ensemble.

Training ≠ inference

Training: foto latih + label laboratorium → sampling acak, augmentasi, loss, gradien → bobot model.

Inference: foto sampel baru + PPM + bobot → grid tile semua foto, TTA → kurva. Label uji tidak tersedia dan tidak dibutuhkan.

CSV akhir: sample_id + 11 persentase; 200 mm = tepat 100.

03 / Model anatomy

Arsitektur yang mengikuti sifat tanah.

Berbagi encoder antar skala menghemat parameter. Agregasi attention berjalan linear terhadap jumlah tile; arsitektur ini tidak menggunakan Transformer.

Persamaan metode ↗

Perjalanan bentuk tensor

B = batch, T = tile per sampel, S = skala. Ukuran diambil dari konfigurasi Kaggle aktif, bukan konfigurasi default B=8.

Di dalam GrainBlock

x → [DW 3×3 ∥ DW 3×3 dilasi 2]
→ 1×1 mix → GN → GELU → gate
→ x + transformasi(x)

Depthwise mencari pola lokal per kanal; dilasi memberi konteks. GroupNorm menjaga normalisasi pada batch kecil. Gate kanal memilih fitur yang berguna.

Stem: 5×5 stride 2. Tahap kanal: 32 → 48 → 96 → 160 → 224; blok: 1 / 2 / 2 / 3 / 2. Pooling spasial mean ∥ std menghasilkan 448 fitur per skala.

Dua skala → 896 → embedding tile 256 → mean ∥ std ∥ attention (768) → MLP 256 → 11 logit.

Skala fisik

Foto distandardisasi ke 10 px/mm. Bidang 25,6 mm memakai 256 piksel; bidang 102,4 mm memakai 1.024 piksel lalu dikecilkan ke 256.

Tekstur & pandangan

RGB + Sobel + Laplacian → lima kanal. Semua tile sampel dipool sebelum kurva diprediksi; sampling lebih banyak tidak menambah label independen.

Head terkendala

11 logit → softmax massa positif → cumsum. Invariant fisik valid sejak desain. Postprocess memastikan batas dan endpoint CSV tepat 100.

Massa pertama adalah ≤0,002 mm; massa kedua hingga kesebelas berada di interval antar diameter. Ini representasi massa fraksi, bukan jumlah butiran dalam foto.

Kalkulator durasi yang transparan

Nilai awal 0,5 detik/step adalah asumsi simulasi. Impor profile.json Kaggle untuk menggantinya dengan median benchmark; biaya data loading dan evaluasi diestimasi terpisah.

Tidak ada benchmark yang diimpor.

Harga $0 menggambarkan penggunaan kuota gratis yang tersedia. Tidak menjamin ketersediaan GPU. Jam kalender belum termasuk antrean atau setup; kalkulator memakai satu GPU.

Forward Conv + Linear / batch—GMAC; perkiraan FLOP ≈ 2×MAC
Bobot FP32—Hanya parameter
AdamW + grad + EMA—Belum termasuk aktivasi / buffer
Cbatch = O(BTS · Cencoder + BTSDencD + BTDh + BD² + BDK)
Ctrain = O(R G E Q · Cbatch)

R=seed, G=fold, E=epoch, Q=step/epoch, K=11, D=embedding, h=hidden attention. Encoder didominasi konvolusi H×W×k²×Cin×Cout dan depthwise H×W×k²×C. Detail memori, inference, classical track, dan asumsi backward tersedia di paper.

Urutan eksekusi yang disarankan di Kaggle
  1. Attach dataset kompetisi; pilih accelerator dan periksa Python, Torch, CUDA serta semua perangkat.
  2. Jalankan audit + baseline mean/median sebelum training serius.
  3. Jalankan profiler dan smoke 1 epoch / 2 step / 1 fold. Pastikan loss finite, VRAM, waktu, checkpoint.
  4. Jalankan C100 full CV dan B000 pembanding. Bila OOM kurangi batch, tile, atau chunk secara terdokumentasi.
  5. Jalankan ablation satu per satu; lalu tiga seed untuk kandidat terpilih.
  6. Ekspor research_report.json, validasi submission, arsipkan, dan restore inference dalam sesi bersih.

06 / Evidence before claims

Target & roadmap menuju riset lengkap.

100% pengembangan rilis lokal berarti checklist perangkat selesai. 100% riset membutuhkan gate data nyata, evaluasi, ablation, submission, dan reproduksi hasil.

Fondasi perangkat

Pipeline, model & dokumentasi

Konfigurasi, tests sintetis, audit, constrained head, pelatihan, inferensi, dashboard, paper metode, profiler, laporan.

Menunggu data nyata

Audit + baseline + C100

G1/G2: audit dataset Kaggle dan CV penuh. Catat baseline A000/A001/B000, waktu GPU, serta perbedaan kamera.

Menunggu eksperimen

Ablation + final + paper hasil

G3–G5: uji komponen dan seed, CI95, restore inference, submission, hasil dan batas penelitian.

Kriteria penerimaan

  • 0 kurva invalid, 0 ID salah, 0 overlap kelompok di fold.
  • CV EMD lebih rendah dari baseline statistik dan pembanding neural pada fold identik.
  • Target riset usulan: ≥10% perbaikan relatif dari baseline terbaik; bukan jaminan skor.
  • Perbaikan pada mayoritas kelompok, evaluasi tiga seed (42 / 123 / 2026), uncertainty dan error kasus terburuk.
  • Final inference dapat diulang dari checkpoint tanpa training.

Matriks ablation siap dijalankan

IDPertanyaan

Head terkendala diuji sebagai invariant. B000 tetap GrainBlock tanpa texture/satu skala; belum merupakan vanilla CNN yang cocok untuk klaim superiority universal.
