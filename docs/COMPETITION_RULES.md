# Competition Rules Audit

This is a live gate document. Before final training and submission decisions, verify directly from Kaggle:

- official evaluation equation;
- exact submission columns and order;
- external-data policy;
- pretrained-weight policy;
- notebook/internet restrictions;
- team and submission limits;
- competition end date;
- licensing and redistribution constraints.

The project may use stricter scientific rules than the competition itself.
