# Metrics

## Primary metric

The primary metric is the official Kaggle competition EMD implementation. The current repository implementation is explicitly provisional until P4 verifies the live evaluation definition.

## Secondary diagnostics

Planned diagnostics include per-diameter MAE, overall MAE/RMSE, interval-mass MAE, clay/silt/sand/gravel fraction MAE, D10/D30/D50/D60 errors where valid, fold standard deviation, cross-view disagreement, monotonicity violations, and endpoint violations.
