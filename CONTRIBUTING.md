# Contributing

Every substantive experiment must be reproducible from a committed configuration and linked to an experiment ID.

Do not commit competition data, large checkpoints, credentials, or untraceable results.

Recommended commit prefixes:

```text
feat(model): ...
feat(data): ...
feat(loss): ...
fix(metric): ...
exp(C003): ...
docs(readiness): ...
test(model): ...
```

Changes to the validation grouping key or official competition metric must be recorded in `docs/DECISIONS.md`.
