# Experiment Registry

Experiment families:

- Axxx: non-neural/statistical baselines
- Bxxx: simple custom CNN baselines
- Cxxx: GrainBlock and physical-scale experiments
- Dxxx: multi-view PhyGrainNet
- Exxx: losses
- Fxxx: ablations
- Gxxx: TTA
- Hxxx: ensembles

Every result used in model selection or a paper must be linked to a committed config and Git commit.
